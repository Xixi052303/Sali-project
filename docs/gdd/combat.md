# 战斗、食客与 Boss

## 餐车耐久与失败

**章节状态：核心公式、紧急维修`12%～55%`区间、溢出护盾及其局内持续规则已确认；攻击强度比例、取整与护盾上限待定。**

### 系统目的

餐车耐久是本作唯一失败资源，用一个数值承接漏客、远程投掷、精英漏过和 Boss 攻击，避免同时管理厨师生命与投诉容量。

### 已确认规则

- 初始与最大餐车耐久均为 `100`。
- 每局初始临时护盾为`0`；护盾不是第二条失败资源，不计入餐车耐久上限。
- 未满足的普通食客接触餐车后，造成等于其 `剩余胃口` 的耐久损失，留下投诉反馈并立即离场。
- 只有食客与餐车的可见主体实际相交才视为接触；横向绕开的普通食客到达屏幕底部后静默离场，不造成伤害、不提供掉落，也不计作击败。
- 普通远程攻击造成 `攻击强度比例 × 攻击者剩余胃口` 的耐久损失。
- 精英接触餐车后，造成等于其 `剩余胃口` 的耐久损失，随后离场且不提供特殊强化。
- Boss 普通攻击使用 `攻击强度比例 × Boss剩余胃口` 的基本关系；重击使用更高比例。
- 受击时先消耗临时护盾，再由剩余伤害扣除餐车耐久；即使伤害完全被护盾吸收，也会正常触发本次受击和`1s`无敌时间。
- 紧急维修按当前最大耐久的`12%～55%`计算实际点数，先恢复当前耐久，超过耐久上限的部分完整转化为临时护盾。
- 临时护盾在当前单局内持续保留，新的溢出维修点数继续加入现有护盾；不会随时间、前进阶段、精英或 Boss 切换自动清除，只会在承伤时消耗，重新开局时随局内状态重置。
- 每次受击后获得 `1s` 无敌时间，同一攻击不能重复结算。
- 耐久归零时餐车失控停下、当局结束；不表现厨师死亡或食客受伤。

### 反馈

- 餐车受击时短促震动、掉落少量不影响识别的食材碎屑，并在耐久区闪烁对应损失。
- 临时护盾存在时在底部耐久区域显示其当前点数；护盾损失与耐久损失使用不同颜色，单次攻击同时穿透两者时分别显示实际损失。
- 漏客时食客将投诉纸拍在餐车侧面后离场；投诉纸是耐久损失反馈，不建立第二条投诉计量。
- 无敌时间用餐车轮廓闪烁表示，不使用长时间全屏遮罩。

耐久公式的未决参数见[开放问题](open-questions.md#餐车耐久)。

## 普通食客

**章节状态：占位、复杂度边界、内容模板职责与基础单位小鼠已确认；其余正式阵容、数值和具体机制待定。**

- 普通食客的基础单位与基础美术身份确定为小鼠，对应当前`basic_guest`模板；其胃口倍率`1.0`继续作为其他食客倍率的参照。
- 当前构筑验证切片暂以狐狸承接既有快速模板、青蛙承接既有远程模板；这两项只是在不新增机制前提下接入现有模型，不确认它们属于正式八分钟阵容。
- 普通食客通常占据相邻两个逻辑区域，玩家可以横向绕行。
- 普通食客主要通过胃口、移动速度、体型、占位组合和数量形成差异。
- 食客的身份层级与行为类型分别定义；“普通/精英”不等同于具体行为，“快速”只由移动速度体现。
- 单个普通食客最多拥有一个简单、直观且可读的特殊行为，例如远距离攻击餐车。
- 单个普通食客不叠加阶段变化、免疫、召唤和多层复合机制。
- 食客个体模板负责身份、行为、胃口倍率、移动速度、占位和攻击参数；出场时间、数量、队形、间隙和阶段归属由波次或时间轴负责。
- 普通食客未被满足并接触餐车时，按剩余胃口损伤耐久后离场。
- 普通食客可以从餐车两侧绕过；未与餐车主体相交时，经过餐车高度或离开屏幕底部均不损伤耐久。
- 普通食客生成时独立均匀抽取奖励百分位`p`，实际胃口锁定为`round(基准胃口 × 食客倍率 × (1+0.4p))`；基础胃口不缩放，同一个`p`决定击败后小份奖励门的初始稀有度与数值。
- 精英不参与普通食客的随机稀有度，仍只按生成时基准胃口和自身倍率锁定实际胃口；所有食客生成后都不会因时间继续增长。
- 正式流程按路程使用两段基准胃口：`0%～50%`为`15→350 / 指数2.1`，`50%～100%`为`350→12000 / 指数2.1`。普通、快速、远程与精英倍率依次为`1.0 / 0.75 / 1.5 / 1.5`。
- 当前实现允许食客在画面上方约`640px`范围内提前存在、成为目标并受到投喂，使持续时间和远距离攻击仍有价值。
- 食客受到投喂时使用短促亮闪和轻微缩放反馈，不改变满意离场的非暴力表达。
- 普通食客头顶仍只显示当前胃口数字，数字颜色使用其奖励稀有度色，不额外增加进度条。

### 下一验证原型

- 下一种普通食客优先验证“三席大桌客”：连续占据三个相邻区域，移动速度低于基础食客，胃口倍率高于基础食客，不附加特殊行为。
- 三席大桌客被满足后仍遵循“一位普通食客对应一道同宽奖励门”，即留下三区域宽奖励门。
- 本轮只确认原型方向，不确认正式名称、物种、美术身份、精确倍率、速度、出现阶段和频率，也不加入当前构筑验证切片。

正式食客阵容见[开放问题](open-questions.md#普通食客)。

## 精英

**章节状态：数量、占位、移动、默认胃口倍率、漏过与奖励规则已确认；身份与其他战斗参数待定。**

- 每局共有 6 只精英。
- 精英不会移动，并横跨全部六个逻辑区域，因此玩家不能绕过。
- 精英在生成时按当时普通食客基准胃口的`1.5`倍锁定实际胃口。
- 精英负责阶段性火力检查和特殊强化投放，不要求唯一指定食材。
- 精英未被满足而接触餐车时，按剩余胃口损伤耐久，随后离场且不给奖励。
- 精英被满足后提供混合随机特殊三选一。

精英身份与参数见[开放问题](open-questions.md#精英)。

## 两场 Boss 战

**章节状态：两场结构、停止前进、默认胃口倍率和基本交互已确认；Boss 身份、职责、技能与正式调优待定。**

### 通用规则

- 每局只有两场Boss战：中途Boss位于`50%`路程，最终Boss位于`100%`路程，两场首轮目标时长均约`25s`。
- Boss 登场后停止向前移动，也停止生成普通食客、普通强化门和精英。
- Boss 可以在画面上半部横向移动。
- Boss 一般通过有预警的远程攻击、范围攻击或其他可躲避行为攻击餐车。
- 玩家可在开战站位与 Boss 之间的道路范围内连续前后左右移动，纵横向共用普通横移速度；餐车不能越过或贴进 Boss，自动攻击保持不变。
- Boss 攻击遵循“预警、结算、反击窗口”的基本节奏，不使用无提示随机命中。
- Boss 在登场时按当时普通食客基准胃口的`3`倍锁定实际胃口；后续基准增长不再改变本场上限。
- 中途 Boss 胜利后提供局内特殊三选一并恢复前进。
- 最终 Boss 胜利后进入结算；首胜解锁后续内容。

Boss 的身份、技能和参数见[开放问题](open-questions.md#boss)。
