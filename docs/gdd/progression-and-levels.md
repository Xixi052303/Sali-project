# 关卡与局外成长

**章节状态：内容解锁方向已确认；章节、场景与解锁树待定。**

- 失败不消耗体力或局外资源。
- 局外成长只解锁食材、特殊强化、Boss 或其他内容，不永久增加满足值、餐车耐久、移动速度或资源倍率。
- 当前原型默认解锁全部现有食材；后续建立局外解锁树时，开局随机候选池只使用当时已解锁的食材。
- 当前实现只在最终Boss首胜后持久化一个完成/内容解锁资格标记，尚未据此锁定或开放具体食材、特殊强化、Boss或章节；当前三种食材仍默认全部解锁。
- 首版使用一名通用厨师，其姓名、年龄、属性和背景待定。

关卡、角色与解锁结构见[开放问题](open-questions.md#关卡与局外成长)。
