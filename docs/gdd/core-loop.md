# 核心循环与单局结构

## 核心循环

**章节状态：核心循环、六区操作、正式距离排程和六档环境压力已确认。**

```text
从已解锁食材的随机开局门中选择一种
        ↓
自动前进、自动投喂，连续横移绕行与选门
        ↓
高频普通强化提高全局厨房或餐车属性
        ↓
遭遇静止且横跨六区的精英
        ↓
满足精英，获得特殊三选一
        ↓
约第五分钟进入中途Boss战，停止前进
        ↓
胜利后获得局内特殊强化并恢复前进
        ↓
继续普通门、普通食客与精英
        ↓
进入最终Boss战，停止前进
        ↓
结算通关与首胜内容解锁
```

## 玩家输入与六区场地

- 按住并横向拖动时，厨师和餐车连续跟随手指横坐标移动。
- 松开手指后保持当前位置，不自动回中。
- 玩家不能主动控制前进速度、瞄准、普通攻击或释放技能。
- 场地横向划分为六个逻辑路线区域，用于生成、占位、强化门和危险预警判定。
- 六区不等于硬车道；餐车不会吸附区域中心，玩家可以在区域间连续移动。
- 普通强化门的左右选项原则上各占三个逻辑区域。

## 自动攻击与目标选择

- 所有食材独立按自身间隔自动攻击。
- 默认目标是前方有效范围内距离餐车最近的未满足食客、可攻击普通门面板或餐车当前横向位置能够取得的食客奖励门。
- 餐车位于门的左半区时只把左侧门作为候选，位于右半区时只把右侧门作为候选；当前侧达到上限后不会自动转攻另一侧。
- 餐车越过门线时严格只结算一个选项；中心点归右侧，不存在同时取得两侧效果的判定区。
- 食客奖励门只占原食客对应的横向区域；餐车必须经过该区域才取得奖励，绕开即错过。
- 同距离时优先选择更接近餐车横坐标的目标，再按进入场景的先后顺序稳定裁决。
- 横向移动会改变最近目标和弹道方向，是玩家调整优先目标的主要手段。
- 没有有效目标时仍按各食材间隔朝正前方自动攻击；需要目标角度的食材仅在存在有效目标时改用目标方向，不积存攻击轮次。

## 单局结构

**章节状态：约八分钟、50次普通门、6只精英、2场Boss及正式路程节点已确认。**

- 有效游戏时间目标约`480s`，包括两场各约`25s`的Boss；选择界面停表，目标前进时间约`430s`。
- 前进阶段按累计路程生成50次普通强化门和235个普通波次；沿用每四波一次双客的当前密度时约为293只普通食客。
- 普通强化门只在前进阶段生成，两场 Boss 战期间停止。
- 每局共出现 6 只精英和 2 场 Boss，合计承担 8 次特殊强化或内容解锁节点。
- 六只精英位于路程`12.5% / 25% / 37.5% / 62.5% / 75% / 87.5%`，两场Boss位于`50% / 100%`。
- Boss 登场后停止向前移动，Boss 结束后中途战恢复前进，最终战进入结算。

### 正式距离与压力流程

- 胃口只随已完成路程增长：`0%`为`15`、`50%`为`350`、`100%`为`12000`，前后两段首轮指数均为`2.1`。
- 压力在路程`18.75% / 31.25% / 50% / 68.75% / 81.25%`切换，六档前进倍率依次为`1.0 / 1.1 / 1.3 / 1.7 / 2.3 / 3.0`。
- 食客、普通门、小份奖励门与背景使用同一前进倍率。普通投射物迎面风阻为`1.25 × 基础滚动速度 × (当前倍率 - 1)`，用于稳定不同阶段的相遇时间。
- 侧漂随压力增至`60px/s`。首段方向由局种子决定，之后逐段交替；切换时提前提供方向反馈。
- 疲劳与颠簸把基础横移逐步降至`80%`，只形成持续阻力与纸艺表现，不随机推车。蘑菇不受位移风，巨型法棍只承受普通投射物`25%`的风偏。
- Boss、特殊选择和其他选择阶段都暂停路程，因此不会生成新普通食客、普通门或抬高后续对象胃口；已入队的安全生成请求继续保持顺序。

### 排程通用约束

- 普通食客、精英与普通门可以同屏；同一横向路径在生成时保留预测安全距离，不同横向路径允许并行，运行中始终以实际几何不重叠为底线。
- 固定斜俯视角同时保留从远方生成点到餐车前的四段有效道路；食客与普通门从远端进入，使玩家能更早读取后续组合。
- 精英与Boss事件是路程请求点；若仍有占位冲突则保留请求，安全后再生成，后续请求不会越过队首。
- Boss登场前处理仍未结算的普通门；进入Boss时清理前进对象，避免停止滚动后叠在战斗空间。
