## 文档状态管理

| 状态 | 含义 | 使用规则 |
| --- | --- | --- |
| 已确认 | 已由用户明确决定，继续指导当前设计 | 后续修改时必须说明替代关系 |
| 待定 | 只有方向、候选或需要原型验证 | 不得直接当作制作规格或最终数值 |
| 已废弃/已替代 | 曾经提出，但已经被新决定替代 | 只保留决策摘要，不再指导制作 |

## 事实源规则

- 每条完整规则只在上表指定的领域文档中维护；其他文档使用摘要和链接。
- `data/` 中的资源与时间轴负责当前原型精确数值；GDD 负责设计语义、边界和状态。
- 开放问题不视为制作规格；只有确认后才迁入对应领域文档，并同步更新本索引。
- 已替代或废弃的规则只在[决策记录](decision-log.md)中保留，不继续指导实现。
