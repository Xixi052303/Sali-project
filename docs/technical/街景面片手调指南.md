# 街景面片手调指南

## 打开位置

1. 在 Godot 文件系统中双击`scenes/world_background_3d.tscn`，直接编辑背景子场景。
2. 在场景树展开`StreetProps`，选择要调整的`PropBench`、`PropBin`、`PropSign`等`Sprite3D`节点。
3. 保持3D视图可见，修改检查器属性即可实时预览。

## 调整裁剪

- 在检查器的`Sprite3D > Region`中保持`Enabled`开启。
- 修改`Region Rect`的`x / y / width / height`；这些值对应`assets/image/街景.png`中的原图像素坐标。
- `x、y`移动裁剪框左上角，`width、height`改变取图范围。先校准裁剪，再调整场景尺寸，避免用缩放掩盖裁错的透明边缘。

## 调整大小与摆放

- 优先修改`Pixel Size`做等比整体缩放；值越大，面片在世界中越大。
- 只有素材本身比例需要修正时，才修改`Transform > Scale`：`x`控制宽度，`y`控制高度。
- 修改`Transform > Position`摆放：`x`控制道路左右，`y`控制离地高度，`z`控制前后位置。
- 需要镜像时使用`Flip H`，不要输入负的节点缩放。

## 新增街景

复制任一现有街景节点并把副本继续放在`StreetProps`下，再修改名称、`Region Rect`、`Pixel Size`和位置。运行时会自动收集该组下所有`Sprite3D`并参与道路滚动，不需要修改脚本名单。

调整完成后运行`run_3d.tscn`，重点检查裁剪边缘、离地高度、远近尺度、左右遮挡和循环回卷时是否突然跳位。
