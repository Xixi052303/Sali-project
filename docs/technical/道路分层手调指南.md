# 道路分层手调指南

## 编辑入口

在 Godot 文件系统中直接打开`scenes/road_segment_3d.tscn`。六个循环路段都实例化这一份场景，因此不要逐个修改`world_background_3d.tscn`中的路段实例。

## 节点职责

- `RoadSurface`：中央马路，使用`马路.png`，顶面高度为`Y = 0`。
- `LeftCurb`、`RightCurb`：左右路沿，使用对应路沿贴图。
- `LeftSidewalk`、`RightSidewalk`：左右人行道，使用对应人行道贴图。

路沿和人行道当前使用`BoxMesh`，厚度均为`0.1m`，节点中心位于`Y = 0.05m`，因此顶面为`0.1m`。

## 调整高度与宽度

- 修改某层宽度时，调整对应`BoxMesh`或`PlaneMesh`的`Size X`，再同步调整节点`Position X`以保持边缘拼接。
- 修改抬高高度时，同时设置`BoxMesh > Size Y = 目标高度`和`Position Y = 目标高度 ÷ 2`，这样底面仍贴在马路高度。
- 路段长度必须保持`12.8m`；改变长度还需要同步修改`WorldBackground3D.ROAD_TILE_LENGTH`和六个路段的初始`Z`间距，否则滚动时会出现接缝。
- 贴图左右方向已经按节点名称装配。替换图片时保持左右资源语义一致，避免路沿和人行道内外翻转。

调整时直接在3D编辑器预览`road_segment_3d.tscn`；保存后运行`world_background_3d.tscn`和`run_3d.tscn`，检查近景高度边缘、中央六区对齐、远景收束和循环接缝。
