# 道路分层手调指南

## 编辑入口

在 Godot 文件系统中直接打开`scenes/road_segment_3d.tscn`。六个循环路段都实例化这一份场景，因此不要逐个修改`world_background_3d.tscn`中的路段实例。

## 节点职责

- `RoadSurface`：中央`PlaneMesh`马路，使用`马路.png`，宽约`6.04m`，平面高度为`Y = 0`。
- `LeftCurbFace`、`RightCurbFace`：左右竖直`QuadMesh`路沿面，高`0.5m`、中心位于`Y = 0.25m`，右侧当前镜像复用`左路沿.png`。
- `LeftSidewalk`、`RightSidewalk`：左右`PlaneMesh`人行道，各宽`1.69m`，平面高度为`Y = 0.5m`，分别使用左右人行道贴图。

当前路段长度为`12.8m`，从左人行道外缘到右人行道外缘的可见总宽约`9.44m`。路沿只有朝向马路的竖直面，不使用旧版`BoxMesh`顶面；人行道平面与路沿顶端在`Y = 0.5m`对齐。

## 调整高度与宽度

- 修改马路或人行道宽度时，调整对应`PlaneMesh > Size X`，再同步调整节点`Position X`以保持边缘拼接。
- 修改路沿高度时，调整路沿`QuadMesh > Size X`并把节点`Position Y`设为高度的一半；当前路沿面经过旋转，`QuadMesh`的`Size X`对应世界高度。
- 修改人行道高度时直接调整节点`Position Y`，并同步检查左右路沿顶端是否仍与平面对齐。
- 路段长度必须保持`12.8m`；改变长度还需要同步修改`WorldBackground3D.ROAD_TILE_LENGTH`和六个路段的初始`Z`间距，否则滚动时会出现接缝。
- 左右人行道使用各自贴图；两侧路沿面当前通过节点朝向镜像同一张左路沿贴图。替换路沿资源时先在3D视图检查方向，不要假设存在独立的右路沿资源引用。

调整时直接在3D编辑器预览`road_segment_3d.tscn`；保存后运行`world_background_3d.tscn`和`run_3d.tscn`，检查近景高度边缘、中央六区对齐、远景收束和循环接缝。
