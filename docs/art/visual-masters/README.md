## 参考图片

- `reference-01-street-material.png`：街景与材质参考。重点参考瓦楞纸断面、撕纸边缘、复古印刷颗粒、道路表面、路边摊、店面和小型街景道具的层次密度。
- `reference-02-gameplay-master.png`：实机效果主参考。重点参考餐车、厨师、食客、料理投射、强化门、纸条信息和道路纵深在同一张`9:16`画面中的整体完成度。

## 已确认方向

1. 实机主体以`reference-02-gameplay-master.png`的纸偶体积、夸张角色轮廓、餐车细节量和玩法对象层次为主要效果目标。
2. 环境以`reference-01-street-material.png`的街区密度、瓦楞纸结构、旧纸肌理和摊位道具丰富度为主要补充。
3. 两张参考共同限定媒介、材质、气质和完成度，不要求复刻画面中的具体对象。
4. 参考图中的英文、图标、三条硬车道、血条布局和红色侧边危险区域不是已经确认的制作规格。

## 实机复核

- 继续保持餐车与厨师、当前食客与危险、料理轨迹、前方强化门、街景装饰的读取顺序。
