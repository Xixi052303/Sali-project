# 构筑验证切片视觉母版图块

这组三张`720×1280`图块只用于比较实机信息层级、六区感知和纸层关系，不是正式美术资产，也不进入当前 Godot 场景替换。

## 候选

- `candidate-01-readability.svg`：可读性优先。主体居中、对象颜色分组清楚、侧景克制。
- `candidate-02-neighborhood.svg`：街区温度优先。路边摊面和旁观纸偶更多，氛围更热闹。
- `candidate-03-paper-depth.svg`：纸层纵深优先。阴影、前景纸片和错层更强，空间感更鲜明。

## 本轮选择

选择`candidate-01-readability.svg`作为构筑验证切片的视觉锚点。

理由：

1. 餐车、食客、土豆弹道、危险预警和强化门的读取顺序最稳定。
2. 六区由路面色差和虚线暗示，不像吸附车道。
3. 侧景和纸层不会压住当前目标，最适合先检查`720×1280`、`19.5:9`和`20:9`。
4. 后续制作正式母版时可以从候选02吸收街区温度、从候选03吸收纸层厚度，但不得牺牲候选01的信息层级。

## 实机复核

- 缩放到手机尺寸后，首先找到餐车与厨师，其次找到当前食客与危险，再读到投射轨迹和前方门。
- 六区只作为占位判断暗示，不能增加车道中心吸附视觉。
- 高密度阶段保留餐车、目标、普通门和危险预警的独立颜色与轮廓。
- 图块通过后再进入正式纸艺起稿、拆层和资产接入；本轮不直接替换任何现有节点。
