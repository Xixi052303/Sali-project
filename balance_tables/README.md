# 数值表

本目录集中保存数值策划直接查看和修改的 Excel 工作簿。

## 当前文件

- `时间轴.xlsx`：当前竖切片显式事件、两段基准胃口曲线和普通波次阶段节奏的数值主源。游戏每次进入或重开`run_3d.tscn`时直接读取。
- `食客.xlsx`：当前四类食客的身份、单一行为、胃口倍率、速度、占位、攻击与颜色主源。
- `武器.xlsx`：食材武器基础满足、间隔、弹道、范围、持续与环绕参数主源。
- `普通强化.xlsx`：普通门与食客奖励共用候选池的数值主源；只在“普通门”页维护候选、数值区间、门牌文案模板和启用状态，“食客奖励”页为规则说明与只读镜像。
- `特殊强化.xlsx`：特殊候选池、效果数值、食材最高等级与等级倍率主源。
- `小厨西_当前实现数值.xlsx`：跨系统数值总览与公式预览，不直接驱动游戏。

## 修改流程

1. 打开需要调整的小表，先查看其预览或“说明”页（如有）。
2. 修改黄色单元格；绿色字段是结构标识或枚举，确认调用关系后再改。
3. 时间轴的蓝色区域会预览事件压力；武器与强化表也有各自的联动预览页。
4. 保存并关闭 Excel。
5. 重新开始本局或重新运行`run_3d.tscn`。
6. Godot 输出对应的`BALANCE_*_LOADED`表示本局已读取最新表格。

运行中的既有单局不会热替换，避免已生成对象、候选池和累计状态前后不一致。文件缺失、
结构不符或数据非法时，游戏会输出对应的`BALANCE_*_FALLBACK`；时间轴、食客与武器回退
到场景装配的`.tres`，两类强化回退到`run_3d.gd`保留的当前安全值。食客表按四个当前
必需ID整体校验，不会在同一局内混用部分Excel行和部分回退资源。

关键输入使用常量，不使用 Excel 公式；Godot 只读取各工作簿的正式输入页，不依赖首页预览
公式。食客表只定义个体内容，新增行不会自动安排出场；普通食客的个体组合仍由运行逻辑
生成，但波次起止时间、阶段阈值和三段间隔由`时间轴.xlsx`统一控制。
