# 数值表

本目录集中保存数值策划直接查看和修改的 Excel 工作簿。

## 当前文件

- `时间轴.xlsx`：当前竖切片时间轴数值主源。游戏每次进入或重开`run_3d.tscn`时直接读取。
- `小厨西_当前实现数值.xlsx`：跨系统数值总览与公式预览，不直接驱动游戏。

## 时间轴修改流程

1. 打开`时间轴.xlsx`。
2. 先在“时间轴预览”查看曲线、显式事件压力和调参说明。
3. 在“配置”或“事件”工作表修改黄色单元格；蓝色区域会自动预览食客和门的数值。
4. 保存并关闭 Excel。
5. 重新开始本局或重新运行`run_3d.tscn`。
6. Godot 输出出现`BALANCE_TIMELINE_LOADED`表示本局已读取最新表格。

运行中的既有单局不会热替换时间轴，避免已经触发的事件重复执行。文件缺失、结构不符或
数据非法时，游戏会输出`BALANCE_TIMELINE_FALLBACK`并使用
`data/timelines/vertical_slice.tres`。

关键输入使用常量，不使用 Excel 公式；Godot 只读取“配置 / 事件”的输入列，不依赖预览
公式。普通食客波次频率仍由`scripts/run_3d.gd`生成，不在时间轴表中逐条控制。
