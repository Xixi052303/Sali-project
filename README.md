# 小厨西

Godot 4.7 制作的竖屏移动端直接 3D 纸艺玩法竖切片。当前使用可在编辑器预览的临时纸艺节点，不代表正式美术或声音质量。

## 运行

1. 使用 Godot 4.7 打开项目。
2. 运行主场景 `scenes/run_3d.tscn`。
3. 按住鼠标或单指横向拖动餐车；松开后餐车保持当前位置。

`scenes/run_3d.tscn`是项目唯一启动入口；旧 2D 场景已退役并移除。3D 相机、道路、灯光、纸偶、标签和预警均以可编辑场景节点装配。

全部3D场景根节点保持`Scale = 1`并直接使用米制坐标；策划数据与触控输入保留设计像素，只在运行边界按`1像素 = 0.01米`换算。背景子场景单独打开时与主场景中的比例一致。

内部设计分辨率为 `720 × 1280`，桌面调试窗口默认为 `405 × 720`，移动端锁定竖屏。

## 当前可玩内容

- 约3分钟的固定原型流程。
- 固定相机可同时看到从远方生成点到餐车前的四段有效道路；额外路块只用于循环缓冲。
- 12道普通强化门。
- 普通强化门每侧基础血量为`(1+初始百分位)×基准胃口`，高稀有门拥有更高撞门风险；击破后继续攻击可提高奖励，隐藏升值血量不显示。
- 3D版普通门的左右基础胃口分别悬浮在门板上方；普通门与食客奖励门会随实时稀有度跨档立即改变门板颜色。
- 撞门会按所选侧剩余基础血量损失餐车耐久，但仍只取得该侧效果，中心点不会同时取得两侧奖励。
- 八类普通强化使用独立原型区间；持久百分比强化逐次乘算，并显示本次与累计效果。
- 土豆固定竖直发射且不会改变角度；取得“瞄准投喂”后才会在存在目标时按目标方向发射，没有目标时仍持续朝前攻击。
- 法棍直线穿透攻击；所有投射物初始均不会在飞行中追踪目标。土豆与法棍的基础飞行距离约为`0.8`屏与`0.6`屏，弹速和持续时间强化都会扩大实际射程。
- 三类普通食客、一只六区精英；普通食客随机抽取奖励类型与稀有度，并按同一百分位提高生成胃口，精英按当时基准胃口的`1.5`倍生成。
- 食客可以在画面上方提前存在并被攻击，普通门、食客和食客奖励门会按安全距离错开生成。
- 普通食客使用密集波次；只有与餐车主体实际相撞才会损伤耐久，成功绕开并从屏幕底部离场不会造成伤害或掉落。
- 普通食客被满足或撞击击败后，会在原占位留下同宽度、无基础血量且可攻击升值的奖励门；餐车必须经过对应区域才能领取，错过后不会自动吸取。
- 食客、精英和Boss头顶只显示醒目的当前胃口数值，不使用怪物进度条。
- 特殊三选一池包含法棍、全局加量、土豆瞄准和全局穿透`+1`的酱油。
- 一名拥有直线与范围预警的原型Boss，按登场时基准胃口的`3`倍生成。
- 餐车耐久、1秒受击无敌、结算统计和一键重开。
- 餐车耐久固定在屏幕底部靠近厨师视觉焦点；不再常驻显示黑色食材栏。
- 720×1280、19.5:9和20:9竖屏适配结构。

策划案中尚未确认的概率、区间和正式角色内容仍然是原型值。当前时间轴以
`balance_tables/时间轴.xlsx`为运行主源，其他已接入数值仍主要存放在`data/`资源中。
投射物只在发射瞬间确定方向；数据层已预留按食材开启追踪的特殊强化接口。

## 数值表

时间轴可以直接在`balance_tables/时间轴.xlsx`中修改。保存并关闭工作簿后重新开始本局或重新运行
`run_3d.tscn`，游戏会读取最新保存值；运行中的既有单局不会热替换，以免重复触发已经发生的事件。

## 街景手动调整

街景裁剪、大小、位置和新增面片的编辑步骤见[街景面片手调指南](docs/technical/街景面片手调指南.md)。所有街景节点都位于`world_background_3d.tscn/StreetProps`下。

成功读取时输出`BALANCE_TIMELINE_LOADED`。表格缺失或校验失败时输出
`BALANCE_TIMELINE_FALLBACK`，并使用`data/timelines/vertical_slice.tres`作为安全回退。

## 自动校验

核心规则测试：

```powershell
Godot_v4.7-stable_win64_console.exe --headless --path . --script res://tests/test_core.gd
```

完整流程烟雾测试：

```powershell
Godot_v4.7-stable_win64_console.exe --headless --path . --quit-after 20000 -- --smoke-test
```

成功时会输出 `CORE_TESTS_OK` 与 `SMOKE_TEST_OK`。

## 目录

- `scenes/`：可运行场景。
- `scripts/`：单局、单位、武器、界面和数据类型。
- `balance_tables/`：数值策划 Excel 主表与综合查看表。
- `addons/excel_reader_47/`：可跨项目复制的 Godot 4.7 `.xlsx`读取器。
- `data/`：食材、食客、Boss及时间轴安全回退资源。
- `docs/`：玩法策划案。
- `tests/`：无需第三方插件的核心规则测试。
